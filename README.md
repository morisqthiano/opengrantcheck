# OpenGrantCheck

**OpenGrantCheck** is a local-first open-source AI assistant for research proposal compliance checking.

The project aims to help researchers, lecturers, small universities, and research administration offices check whether research proposal drafts comply with grant guidelines and administrative requirements. Many proposals fail not because the research ideas are weak, but because required sections, expected outputs, budget details, references, or formatting rules are incomplete.

## Project Goal

OpenGrantCheck will provide a self-hosted web application where users can upload a grant guideline and a proposal draft, then receive a structured compliance checklist, missing-section detection, and practical revision suggestions.

The system is designed to keep sensitive academic documents under the user's control by supporting local-first and self-hosted deployment.

## Key Features

- Guideline document upload and management
- Research proposal draft upload
- Document parsing for proposal structure and sections
- RAG-based guideline reader
- Compliance checklist generator
- Missing-section detection
- Revision recommendation module
- Dashboard for proposal review results
- Demo dataset and sample proposal templates
- Docker-based self-hosted installation

## Why This Matters

Small universities and early-career researchers often have limited access to research administration support. OpenGrantCheck provides an open-source alternative that can help them review proposal completeness before submission, without depending on closed proprietary platforms.

The project focuses on:

- open-source software
- local-first document processing
- privacy-aware research administration
- reusable templates for academic proposal checking
- support for resource-limited universities and research communities

## Planned Technology Stack

The initial implementation is planned to use:

- Backend: PHP Laravel or Node.js
- Frontend: React.js or Vue.js
- Database: PostgreSQL or MySQL
- AI/RAG: Python-based document parsing and retrieval pipeline
- Deployment: Docker and self-hosted VPS

The final stack may be adjusted during development based on technical feasibility and community feedback.
